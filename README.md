# time2shell announcements

This is the public issue tracker for [time2shell](https://time2shell.com/).

- [Announce an upcoming shell](https://time2shell.com/?view=announce) to prefill a GitHub issue.
- [Open an issue](https://github.com/time2shell/announcements/issues/new/choose) to announce, add, or correct an entry.

Submit only information that is already public. Include a public source for each claim. Do not include credentials, private information, or details that could help someone find a vulnerability before a fix is available.
